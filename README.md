# 21-point
> Проект по дисциплине ОП 03 Основы алгоритмизации и программирование
## Название проекта:
"Игра в 21 очко"
## Проблема, которую решает мой проект:
Проект демонстрирует, как из простых алгоритмов собрать полноценное развлекательное приложение, что мотивирует новичков к дальнейшему изучению программирования. Для конечного пользователя игра решает проблему быстрого и безопасного досуга — даёт возможность сыграть в классическую карточную игру без финансовых рисков прямо в консоли.
## Целевая аудитория:
молодые люди
> 18-30 лет

<li>Разработать диаграмму вариантов использования (Use Case) и блок-схему алгоритма работы игры для наглядного представления функциональности.</li>
<li><ul>Реализовать программный код игры, обеспечивающий:

## Функионал:
- [x] Создание полной колоды из 52 карт (9 числовых и 4 картинки каждой масти).
- [x] Перемешивание колоды случайным образом.
- [x] Раздача по две карты игроку и крупье.
- [x] Отображение одной карты крупье (вторая скрыта) и всех карт игрока с подсчётом текущих очков.
- [x] Преобразование обозначения «T» в «10» при выводе для наглядности.
- [x] Подсчёт очков по правилам: числовые карты – по номиналу, «T», «J», «Q», «K» – 10 очков, «A» – 11 очков.
- [x] Возможность игрока запросить дополнительную карту (ввод «1») или остановиться (ввод «0»).
- [x] Автоматическое решение крупье: берёт карту, если его сумма ≤ 10 (упрощённая логика).
- [x] Проверка на перебор (>21) после каждого хода – если игрок или крупье перебрали, раунд завершается.
- [x] Определение победителя по итогам раунда
- [x] Возможность начать новую игру после завершения текущей (запрос «да/нет»).
- [x] Интуитивно понятный консольный интерфейс с подсказками и разделителями.
- [ ] Наглядное указание карт с мастью и цветом
